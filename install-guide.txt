CIDERLIGHT: HOW TO INSTALL

You need: an Apple Silicon Mac (M1 or newer) on macOS 14 or later, and Minecraft Java Edition.
You only need the one file: the latest Ciderlight .jar. Don't unzip it, and don't double-click it.
The steps below are for Fabric. For NeoForge, see NEOFORGE (BETA) further down.
Don't add Sodium, Iris or Sodium Extra: Minecraft won't start with them alongside Ciderlight.


OPTION A: Modrinth App (easiest)
1. Download the Modrinth App from modrinth.com/app and sign in with your Microsoft account.
2. Make a new instance: Minecraft 26.3, loader Fabric.
3. Open the instance and drag the Ciderlight jar onto its content page.
4. Press Play.


OPTION B: Prism Launcher
1. Download Prism Launcher from prismlauncher.org and add your Microsoft account.
2. Add Instance: Minecraft 26.3, then choose Fabric under Mod Loader.
3. Right-click the instance, choose Edit, open Mods, and drag the jar in.
4. Press Launch. If it asks about Java, let it download Java 25 for you.


OPTION C: The normal Minecraft Launcher
1. Install Java if you don't have it (adoptium.net). The Fabric installer needs it.
2. Get the Fabric installer from fabricmc.net/use. Choose "Download installer (Universal/.JAR)".
   Close Minecraft, open the installer (if macOS blocks it, right-click it and choose Open),
   pick 26.3, and click Install.
3. In Finder, press Cmd+Shift+G and go to:
      ~/Library/Application Support/minecraft
   Make a folder called "mods" if there isn't one, and put the jar in it.
4. Open the Minecraft Launcher, pick the "fabric-loader-26.3" profile, and press Play.


NEOFORGE (BETA)
Ciderlight also comes as a NeoForge mod: the jar with "neoforge" in its name. NeoForge for
Minecraft 26.3 is still a beta, and so is this version of Ciderlight.
1. Follow any option above, but choose NeoForge instead of Fabric (in the normal launcher, run the
   NeoForge installer from neoforged.net instead of Fabric's), and use the NeoForge jar.
2. Optional: to stop a Java warning in the log, add this to the instance's Java (JVM) arguments:
      --enable-native-access=ciderlight
3. Keep NeoForge's update check on (versionCheck in config/fml.toml, on unless you changed it).
   With it off, NeoForge 26.3's title screen crashes. That's a NeoForge bug, not Ciderlight's.
Mods that draw with NeoForge's stencil support may look wrong: Ciderlight doesn't apply it yet.


SHADER SETTINGS
In the game, go to Options > Video Settings and click "Ciderlight..." under the graphics preset.
"Shaders" switches between:
- High: everything at full quality.
- Low: smaller shadow maps, coarser fog, and the world drawn at a lower resolution.
  Much lighter on the graphics chip, with most of the look.
- Off: Minecraft's normal look, still drawn with Metal.
Below it you can turn Shadows, Waving Plants, Water Reflections, Water Waves and Ambient Occlusion off one by
one (Shadows off saves the most), and set the Render Scale (the world's resolution).
Shadows and Ambient Occlusion change straight away; the other settings apply after you quit and
restart the game.

Which one to pick: Low on A-series or lower-tier M chips, High on everything else.
A-series Macs and the plain M1, M2, M3 and M4 start on Low by themselves; all others start on High.


TIPS
- Shaders are on automatically. You don't need OptiFine or Iris.
- Install it on its own first, without other graphics mods.
- It works on any server (it only changes your graphics).
- For a new version, just swap the old jar for the new one.
- Something wrong? Send me a screenshot plus the file logs/latest.log from your
  instance or minecraft folder.
